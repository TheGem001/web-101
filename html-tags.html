The following are some common HTML tags:

HTML Tags

  1. <h1> to <h6> are heading tags.
  2. <b> and <strong> are both bold tags.
  3. <p> is a paragraph tag.
  4. <ul> is an unordered list tag.
  5. <ol> is an ordered list tag.
  6. <i> and <em> are both italic tags.
